#Гибридная система аудиофингерпринтинга
**Программный комплекс для идентификации музыкальных композиций по коротким зашумленным фрагментам.**

Данный репозиторий содержит практическую реализацию (исходный код) для курсовой работы 

Проект демонстрирует решение проблемы ложных срабатываний (False Positives) и падения точности в классических алгоритмах распознавания звука при экстремальных акустических искажениях (шум, клиппинг).

## Архитектура системы (Edge-to-Cloud)
Система построена на двухуровневой гибридной архитектуре:

1. **Уровень 1: Быстрый поиск (DSP Engine)**
   Классический алгоритм комбинаторного хеширования Эйвери Ванга. Извлекает локальные спектральные максимумы (Constellation Map) и выполняет мгновенный поиск по оперативной памяти ($O(1)$) с использованием нечеткой логики (Fuzzy Search).
2. **Уровень 2: Семантическая верификация (AI Engine)**
   Глубокая сверточная нейросеть `OpenL3`. При критическом падении количества найденных хешей (до 1%) алгоритм локализует время старта и передает фрагмент нейросети. ИИ извлекает 512-мерные аудио-эмбеддинги и подтверждает трек с помощью метрики косинусного сходства, игнорируя высокочастотный шум.

##  Структура репозитория

*  `app.py` — **Клиентский модуль.** Содержит логику генерации спектрограмм, извлечения хешей, создания базы данных в ОЗУ и консольный интерфейс для тестирования "на лету" с добавлением белого шума (AWGN).
*  `aiapp.py` — **Аналитический сервер.** Расширяет базовый движок функционалом ИИ-верификации. Загружает веса нейросети и выполняет каскадное подтверждение совпадений.
*  `общее для курсача.ipynb` — **Jupyter Notebook.** Интерактивная среда математического моделирования. Содержит стресс-тесты, расчет метрики выживаемости пиков (Peak Survival Rate) и визуализацию всех этапов: от временной волны до мел-спектрограммы и векторов признаков.

##  Ключевые особенности реализации
* **Silence Gate (Детектор тишины):** Программный предохранитель, блокирующий комбинаторный взрыв хешей и зависание системы при подаче пустого аудиосигнала.
* **Fuzzy Search (Нечеткий поиск):** Допуск в $\pm 1$ частотный бин, компенсирующий спектральный дрейф при низких значениях SNR.
* **Temporal Pooling (Агрегация):** Усреднение эмбеддингов по времени для защиты семантического ядра трека от случайных шумовых артефактов.
